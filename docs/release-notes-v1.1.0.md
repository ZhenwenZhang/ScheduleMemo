## 日程备忘录 v1.1.0

首个公开发布版本：一个纯本地的 macOS 菜单栏日程应用，点开菜单栏图标即可管理日程。

### 功能亮点

- **菜单栏常驻**：显示下一项日程（如 `14:00 项目周会`）；有逾期时显示红色逾期数量；可切换为今日数量或仅图标。
- **点开即用**：左键弹出面板，右键弹出快捷菜单（新建 / 今日概况 / 设置 / 数据文件夹 / 退出）。
- **中文自然语言快捷添加**：输入「明天 10:00 交报告」「周三下午3点 复盘」「3天后 取快递」回车即建。
- **完整编辑**：日期、时间 / 全天、提醒提前量、优先级、备注；日期快捷按钮（今天 / 明天 / 后天 / 下周一）。
- **完成与撤销**：勾选完成、折叠的已完成列表；删除和完成均可撤销。
- **到点提醒**：菜单栏下方弹出提醒卡片，可完成或 10 分钟后再提醒；全天日程默认 9:00 提醒；提示音可关闭。
- **本地数据**：JSON 明文存储 + 自动备份，损坏可恢复；支持导出备份。
- **体验细节**：深色模式自适应、Esc 逐层关闭、失焦自动收起、单实例、开机自启。

### 安装

1. 下载 `ScheduleMemo-1.1.0.dmg`（通用二进制，Apple Silicon / Intel 均可）；
2. 打开后把 `ScheduleMemo.app` 拖入 `Applications`；
3. 首次打开若提示「无法验证开发者」，请右键点击 App → 打开，或执行：
   `xattr -dr com.apple.quarantine /Applications/ScheduleMemo.app`。

### 兼容性

- macOS 14 及以上（开发环境 macOS 26/27 已验证）。
- 未做 Apple 公证；ad-hoc 签名，仅通过 DMG 分发。

### 校验

SHA-256 见 `ScheduleMemo-1.1.0.dmg.sha256`。
